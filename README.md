# 飞书渠道数据汇总工具

一个面向 Windows 的飞书多维表格批量汇总工具。它可以从多个飞书来源视图或 Excel 工作表读取数据，经过字段映射、查重和预检后，安全写入同一张目标多维表格。

![飞书渠道数据汇总工具主界面](docs/images/app-overview.png)

## 主要功能

- 批量导入 `.xlsx` / `.xls` 工作簿，支持选择工作表和预览数据。
- 汇总多个飞书多维表格来源，来源可独立启用或停用。
- 来源字段与目标字段名称可以不同，也可以为整批数据填写固定值。
- 按日期范围读取，统一使用 `Asia/Shanghai` 时区。
- 写入前显示读取、已存在、待新增和异常数量。
- 使用多个字段组合查重，并正确处理来源中的重复记录。
- 每 500 条自动分批写入，完成后再次读取目标表进行复核。
- 同步记录只保存在本机，可以删除单条记录或清空历史。

## 安装与运行

需要 Windows 和 Python 3.11 或更高版本。

```powershell
git clone https://github.com/SmartLogicHub/feishu-channel-importer.git
cd feishu-channel-importer
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

也可以构建为单文件 Windows 程序：

```powershell
python build.py
```

构建结果位于 `dist/飞书渠道数据汇总工具.exe`。

## 飞书应用权限

在飞书开放平台创建企业自建应用，并为应用开通多维表格读取与写入权限。目标多维表格和每个来源表也需要授权给该应用。

第一次启动后：

1. 打开“设置”，填写 App ID、App Secret 和目标多维表格视图链接。
2. 点击“测试连接并读取字段”。
3. 连接成功后保存设置。

凭证会使用 Fernet 加密后保存在当前用户的 `.feishu_importer` 配置目录。密钥与密文位于同一目录，因此它用于避免明文保存，不等同于 Windows Credential Manager 或 DPAPI 的系统级保护。请保护好自己的 Windows 账户和配置目录。

## Excel 批量导入

1. 打开“Excel 导入”，选择 `.xlsx` 或 `.xls` 文件。
2. 选择要读取的工作表。
3. 将 Excel 列或固定值映射到目标字段。
4. 勾选允许写入的字段和用于查重的字段。
5. 点击“预检 Excel”，确认数量与异常。
6. 点击“确认导入”，通过二次确认后写入。

Excel 日期支持标准日期、Excel 日期序号和数字字符串。空值或无法转换的日期会显示为异常，不会被静默写入。

## 多来源每日同步

1. 在“来源管理”中添加一个或多个带 `table`、`view` 参数的飞书视图链接。
2. 配置日期字段、来源到目标的字段映射和查重字段。
3. 在“每日同步”选择日期范围与来源。
4. 先执行预检，再确认同步。

未勾选的目标字段不会写入；公式、查找引用和创建时间等只读字段不会出现在可写字段列表中。

## 安全约束

- 预检阶段只读取数据，不调用写入接口。
- 写入必须经过明确按钮操作和二次确认。
- 只写用户勾选的字段，不修改目标字段结构或类型。
- API 错误信息会过滤凭证和访问令牌。
- 写入后会重新读取目标表，检查本批数据是否完整存在。
- 本地同步记录不保存 App Secret、访问令牌或请求头。

## 测试

```powershell
python -m unittest discover -s tests -v
```

测试覆盖 Excel 读取、飞书 API 分页与批量写入、字段映射、日期归一化、查重规划、写后复核和主要 UI 流程。

## 当前限制

- 仅支持连续日期范围。
- 不包含后台定时任务。
- 应用不会自动修改飞书字段类型或单选项。
- `.xls` 支持情况取决于本机安装的 pandas Excel 读取依赖。
